## Key Design Decisions

### Why `AgentTalk/` and `rust-core/` at the same level?

The Xcode project and the Rust crate are siblings. This keeps them independently buildable (you can run `cargo build` in `rust-core/` without Xcode) while maintaining a clear boundary. The pre-build script in `project.yml` bridges them by running `cargo` before `xcodebuild`.

### Why `Bridge/.gitignore` ignores everything except `.gitkeep`?

The `Bridge/` directory receives generated swift-bridge output files (`.swift` and `.h`). These are build artifacts — regenerated on every `cargo build` — so they're gitignored. The `.gitkeep` keeps the directory in the repo so it exists when Xcode tries to find it.

### Why are models and target directories gitignored?

- `rust-core/target/` — Cargo build output (~hundreds of MB of compiled C++ from whisper.cpp)
- `rust-core/generated/` — swift-bridge codegen output
- `models/*.bin` — Whisper model files (~1.5 GB each)
- `build/` — Xcode build output
- `AgentTalk.xcodeproj/` — Generated by xcodegen from `project.yml`
