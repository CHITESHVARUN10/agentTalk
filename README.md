# AgentTalk

Offline, macOS-native AI dictation. Press a global shortcut, speak, release — AgentTalk transcribes locally with Whisper and puts the text on your clipboard. No cloud, no upload, no account.

![Platform: macOS 14+](https://img.shields.io/badge/platform-macOS%2014%2B-lightgrey) ![Language: Swift + Rust](https://img.shields.io/badge/language-Swift%20%2B%20Rust-orange) ![License: MIT](https://img.shields.io/badge/license-MIT-green)

## Features

- **Global hotkey (⌘⇧D)** — start/stop dictation from any app, no accessibility permission required
- **On-device transcription** — Whisper Turbo (`ggml-large-v3-turbo`) runs locally via Metal acceleration; audio never leaves your machine
- **Live transcription** — 20-second chunks are transcribed while you keep speaking; the transcript appears almost instantly on stop (overlapping windows + dedupe prevent data loss)
- **Automatic model management** — downloads ~1.5 GB Whisper model on first launch, resumable, checksum-verified, cached
- **Glass HUD** — floating recording pill with live waveform, transcribing state, and a compact transcript card (Copy / Close)
- **Clipboard-first** — transcript copied with standard NSPasteboard APIs; shows up as the newest entry in clipboard managers
- **Menu bar app** — Toggle Dictation from the menu bar mic icon
- **Dock presence** — regular app icon for Finder, Launchpad, Spotlight, and ⌘⇧Tab

## Architecture

```
┌─────────────────────────────────────────────┐
│ SwiftUI — HUD, panel, transcript, menu bar   │
│ AppModel (@Observable) — UI state            │
│ AppDelegate — Carbon hotkey, app lifecycle   │
├─────────────────────────────────────────────┤
│ swift-bridge (FFI, generated)                │
├─────────────────────────────────────────────┤
│ Rust Core (staticlib)                        │
│   state/        — explicit state machine     │
│   config/       — layered TOML config        │
│   model_manager — download, verify, cache    │
│   audio/        — cpal capture, 16 kHz mono  │
│   inference/    — whisper-rs, Metal          │
│   system/       — clipboard, permissions     │
│   hotkey/       — Carbon hotkey bridge       │
├─────────────────────────────────────────────┤
│ whisper-rs → whisper.cpp → Metal             │
└─────────────────────────────────────────────┘
```

Every dictation cycle runs through one state machine:

```
Idle → Preparing → Ready → Recording → Processing (Transcribing) → TranscriptReady → Idle
```

The hotkey (Carbon) and the menu bar both call the same `toggleDictation()` entry point — a single source of truth, no duplicated logic.

## Installation

### Download (DMG)

1. Download the latest release from [GitHub Releases](../../releases) — `AgentTalk-<version>-<arch>.dmg`
2. Open the DMG, drag **AgentTalk** into your Applications folder
3. Launch AgentTalk
4. On first launch: allow **microphone access** (one-time prompt; macOS remembers)
5. The Whisper model (~1.5 GB) downloads automatically on first use

> **Gatekeeper note (unsigned builds):** until the app is signed with a
> Developer ID, macOS may block first launch. Right-click → **Open**, or run:
> ```bash
> xattr -dr com.apple.quarantine /Applications/AgentTalk.app
> ```

### From source

```bash
git clone https://github.com/<you>/agenttalk.git
cd agenttalk
make bootstrap   # installs Rust + xcodegen + builds
make run         # builds and launches
```

## Requirements

- macOS 14.0+
- Apple Silicon (arm64) — Metal acceleration required
- ~1.5 GB free disk space for the model
- Microphone access (prompted on first launch)

## Building

```bash
# 1. Install dependencies
brew install rust    # Rust toolchain
brew install xcodegen

# 2. Generate the Xcode project
xcodegen generate --spec project.yml

# 3. Build (compiles Rust core + Swift app, copies FFI bindings)
./scripts/build.sh
```

Output: `build/Release/AgentTalk.app`

### Build components

| Layer | Toolchain | Notes |
|-------|-----------|-------|
| Rust core | `cargo` | staticlib, whisper-rs + cpal + swift-bridge |
| FFI bindings | `swift-bridge-build` | regenerated by `cargo build` into `rust-core/generated/` |
| Swift app | `xcodebuild` | via XcodeGen spec `project.yml` |

### Package a DMG

```bash
./scripts/package.sh             # release build + ad-hoc signed DMG
AGENTTALK_SIGN_IDENTITY='...' ./scripts/package.sh --sign   # Developer ID
```

Output: `dist/AgentTalk-<version>-<arch>.dmg` (drag-to-Applications install).

### Publish a GitHub release

Tag a version; CI builds DMGs for arm64 + x86_64 and uploads them:

```bash
git tag v0.1.0
git push origin v0.1.0
```

See `.github/workflows/release.yml`.

### Homebrew (optional)

A Homebrew tap recipe is ready in [`docs/homebrew-tap.md`](docs/homebrew-tap.md) — publish the tap repo and users run `brew install --cask agenttalk`.

## Usage

1. Launch AgentTalk.
2. On first launch, the Whisper model downloads automatically (progress shown in the HUD).
3. Press **⌘⇧D** (or use the menu bar mic icon → *Toggle Dictation*).
4. Speak. The recording pill shows a live waveform.
5. Press **⌘⇧D** again to stop.
6. The transcript appears. Click **Copy** (auto-dismisses) or **Close**.

## Configuration

Config lives in `config/default.toml` (overridable via `AGENTTALK_ENV`, env vars prefixed `AGENTTALK_`). Key settings:

| Section | Setting | Default |
|---------|---------|---------|
| `model` | `auto_download` | `true` |
| `model` | `idle_unload_seconds` | `360` (6 min — unloads model from RAM when idle) |
| `audio` | `sample_rate` | `16000` |
| `audio` | `max_duration_seconds` | `300` (5 min) |
| `audio` | `chunk_seconds` | `20` (live transcription window; `0` disables) |
| `audio` | `chunk_overlap_seconds` | `2` (boundary overlap between chunks) |
| `inference` | `language` | `en` |
| `inference` | `n_threads` | `4` |
| `features` | `live_preview` | `false` (show growing transcript in the recording pill; toggle from menu bar) |
| `hotkey` | `key` / `modifiers` | `d` / `command+shift` |

Model storage: `~/Library/Application Support/AgentTalk/models/`

## Known limitations

- **English only** — inference is configured for English dictation (`language: en`, no translation)
- **Whisper Turbo model** — fixed to `ggml-large-v3-turbo.bin`; model upgrades require config changes
- **First transcription slow** — the model loads into memory on first use; subsequent runs reuse the resident engine
- **Paste/auto-paste** — requires Accessibility permission (System Settings → Privacy & Security → Accessibility); plain Copy does not
